What it does

Built for real-world deployment

Not just a demo — every layer is production-hardened

💬

Conversational RAG

A history-aware retriever rephrases every follow-up question before querying Pinecone — so context is never lost across turns.

💾

Persistent History

Every conversation is stored in PostgreSQL via Supabase. History survives page refreshes and is restored automatically when you return.

📊

Retrieval Audit

Each assistant turn stores the retrieved Pinecone doc IDs and response latency — queryable for ongoing evaluation and debugging.

🛡️

Safety Evaluation

A full evaluation pipeline tracks crisis recall, harmful advice rate, professional boundary accuracy, faithfulness, and empathy score.

⚡

Streamed Responses

Gemini responses stream token-by-token directly into the UI. You start reading before the model finishes generating.

✅

69 Tests, 0 Failures

Full pytest suite covering DB functions, app wiring, input validation, FK cascades, session isolation, and graceful degradation.
